# 市场概率图、天气读取与 Paper 市价单验收（2026-09-27）

本记录当前覆盖本地实现、统一自动回归与桌面/手机视觉核验。工作分支 `codex/knyc-chart-orders` 基于 `b8968839caee50b60a2778607d548cb9220ef17a`；最终提交、PR、检查结果、发布 SHA 与正式网页证据由交付负责人完成后补录。当前没有本轮 VM 发布成功或正式网页功能通过的声明。

本轮范围为交易页概率图、所选市场天气读取和人工 Paper 市价/限价操作。平台为 Kalshi 与 Poly US；实盘保持既有门禁，Agent 不使用真实资金验收。原始采集、订单、成交和账户事实保留。本记录不复制旧审计的账户金额、账户身份或订单明细。

## 发布器自动准备天气投影

天气迁移纳入 `scripts/update_knyc_runtime.py` 的发布流程，无需另外手工运行前置独立迁移。

1. 发布器核对精确发布代码、现有 feed 路径与运行条件，写入新版运行文件。
2. 在相关服务启动前，以既有 `nice-weather` 服务账户和运行环境初始化 `FeedStore`，自动执行 `prepare_weather_history(feed.path)`。函数以事件 seq 顺序每批最多 64 条回填、批次提交；游标与派生事实原子保存，可从已提交游标继续。原始事件不删除。
3. 发布核验记录实际回填时长、游标上界、天气点/CLI 版本数量和查询耗时，并抽取有晚到修订的对象时刻核对原始接收证据。采集期间的新事件继续保留；派生游标追齐后由新采集代码原事务维护。
4. 回填完成后启动相关服务，核对 manifest 与页面。回滚仅切兼容代码，保留新增派生表、原始采集和全部新增账目；不使用旧数据库覆盖。

自动迁移及服务启动顺序须随发布器检查核验。该流程尚未在本轮生产 VM 执行，生产结果待补。
