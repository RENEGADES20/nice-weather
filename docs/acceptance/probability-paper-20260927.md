## 实现与数据口径

| 项目 | 已实现行为 | 保留限制 |
|---|---|---|
| 市场概率来源 | Poly US 原生显示样本，必要时最近成交；Kalshi 公开最近 YES 成交。分别保存 `probability`、来源、来源时间与实际接收时间 | 与策略模型概率分列；缺失时不采用盘口中间价或当前值补图 |
| 历史概率 | 新采集直接保存证据；旧 Poly US 仅在精确原始响应仍存在时恢复 | 无实际接收证据的历史继续缺失，不补造过去已知概率 |
| 概率图 | 0–100% 纵轴、真实时间窗口、1H/6H/1D/1W/1M/ALL、对应时点概率和来源显示 | Polymarket 视觉匹配及正式环境流畅度仍待页面复验；绘图简化须保留极值和缺口 |
| 信号与成交 | 复用既有事件；按平台、日期、bin 筛选，S1 双腿各自关联；点击定位与详情 | 本地样本无法替代正式市场上的真实信号和成交标记验收 |
| 天气查询 | 同库对象时间投影，版本变化去重，小批次顺序回填、后续增量维护 | 保留晚到修订、预报日前接收、A→B→A；不按 received_at 日界删选数据 |
| 页面请求 | 天气、历史、报价解耦；首历史页先绘制；切 bin 复用天气；历史和实时合并 | 首次未迁移数据库仍需回填；缓存与后台请求不能改变合约归属 |
| Paper 委托 | 平台选择、YES/NO、买卖、数量；MARKET 无限价且仅 IOC/FOK；LIMIT 保留 GTC/IOC/FOK | 继续 market-price-v1 近似成交，不模拟盘口容量/排队；实际成交与费用以 Nautilus 事实为准 |

图表市场概率不作为 Paper 撮合价格。Paper 继续使用已批准的买 Ask/卖 Bid、mid、最近成交、最近有效报价顺序以及费用、滑点设置；市价只改变委托语义，不解除资金、持仓、精度、市场身份、结算歧义与请求去重检查。

## 合成规模基准

输入数量沿用先前审计中的天气事件计数：CLI 27,204、METAR 13,281、NWS observations 13,609、HRRR 138，合计 54,232。内容由本机脚本合成，包含重复观测快照、预报和 CLI，不读取生产账户或原始私有记录。

| 指标 | 本机结果 |
|---|---|
| 合成输入库 | 267.68 MiB |
| 派生天气点 | 588 |
| 旧逐次扫描查询 | 3.525 秒 |
| 一次顺序回填 | 47.140 秒 |
| 回填后五次查询 | 0.035912、0.016009、0.017312、0.017007、0.017185 秒 |
| 输出一致性 | 新旧天气 sources 与 CLI 逐对象相同 |

本机证据保存在主工作区 `tmp/chart-weather/benchmark.py`、`benchmark-result.json`，未打包生产数据。合成快照的重复率、磁盘性能和并发压力均有局限，且未混入真实大库中的大量无关市场快照，未覆盖首次建索引的真实扫描成本。首次 VM 发布已因此失败；这些数值只描述回填后的天气读取效果，不能用作 VM 升级或响应时间声明。
