## 功能与调用链审核

- 六个原有选项 ID 保持兼容，三个天气差保留，三个价格项映射为 ΔPrice 与天气分钟变化双轴。事件选择、事件基线和自动等待阈值已移除。
- Forecast 新旧 capture 在相同有效时刻插值后比较；同 capture 为零，缺失版本、缺口和过期为 null。分钟变化不跨缺口，价格双方必须为同档 CLOB mid。
- 前端复用计算结果，本地选择不调用 setComponentValue；变化只更新 t 与 t+60。无变化 delta 不写时间轴、不重算整日变化、不更新相同标记。
- 后台天气按来源失效，增量重算从受影响接收分钟开始；点集未变化时绕过整日复制及差异比较。行情 SQL 限定 event/bin/YES token、复用既有 receipt cursor 索引。只保留一个市场日，档位数量受市场合约限制。
- Repricing 返回前不会计算 Trading/Backtest/Audit；其他页签也按激活状态加载。离开 Repricing 后没有其 iframe，返回恢复日期、档位和天气选择。修复原 terminal 合成测试隐式依赖隐藏 Repricing iframe 的问题，直接激活共享组件入口。
