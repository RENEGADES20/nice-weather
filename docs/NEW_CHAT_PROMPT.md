- D:\ALLPROJECTS\weather forecast\docs\PROJECT_CONTEXT.md
- D:\ALLPROJECTS\weather forecast\docs\CURRENT_STATE.md
- D:\ALLPROJECTS\weather forecast\docs\DECISIONS.md

- D:\ALLPROJECTS\weather forecast\docs\SYSTEM_ARCHITECTURE.md

- D:\ALLPROJECTS\weather forecast\docs\RESEARCH_INDEX.md

1. 项目目标和边界；
2. 当前完成情况；

4. 与本次任务直接相关的模块；
5. 你准备采取的下一步。
